Start here: your first commands

Commands are like magic spells you type. Read these one at a time. When you've got one, press “I know this” to fold it away.

1

Turn on cheats

Commands only work in worlds where cheats are turned on. It's best to make a new test world just for trying commands.

  1. Click Singleplayer, then Create New World.
  2. Find Allow Commands and switch it to ON.
  3. Click Create New World.
Already have a world? Inside the world, press Esc → Open to LAN → set Allow Commands: ON → Start LAN World. This only lasts until you quit, so you'll need to do it each time.
  1. Go to Play and pick a world (or make a new one).
  2. Open the world's settings (the pencil ✏️ button next to the world).
  3. Find the Cheats section and turn on Activate Cheats.
  4. Press Play.
⚠️ Achievements: Turning on cheats turns off achievements for that world forever, even if you turn cheats off later. That's why a separate test world is a great idea.
2

Open chat and type a command

  1. Press / (the slash key). Chat opens with the / already typed. (Or press T and type the / yourself.)
  2. Type time set day.
  3. Press Enter. It's morning!
Pro tricks: Press Tab to finish a word for you. Press ↑ (up arrow) in chat to bring back your last command.
  1. Press right on the D-pad to open chat.
  2. Select the text box and type /time set day on the on-screen keyboard. Every command starts with /.
  3. Press the Enter / ✓ button on the keyboard to send it. It's morning!
Pro trick: As you type, the game shows suggestions above the chat box. You can also plug a USB keyboard into the Xbox, which makes typing commands much faster.
/time set day
3

How to read a command

A command is like a sentence: do what → to who → with what → how many.

/give @s diamond 5
/giveThe action: give something.
@sWho gets it: self (you).
diamondWhat to give.
5How many.
Spaces matter! One space between each part. Names with two words use an underscore: golden_apple, oak_log.

In this guide's How it's typed boxes, you'll see two kinds of brackets:

<item>Angle brackets: you must fill this in. Don't type the brackets!
[count]Square brackets: you can skip this part.
4

Who? The @ shortcuts

Instead of typing a player's name, you can use these shortcuts, called target selectors:

@sSelf: you (whoever ran the command).
@pPlayer nearby: the closest player.
@aAll players.
@rA random player.
@eEvery entity: all players, mobs, dropped items, arrows, boats... everything!
⚠️ Be careful with @e. /kill @e removes every mob in loaded chunks, all your pets, and you too. Always add a filter (next lesson).
5

Picking exactly who: filters in [ ]

Add square brackets after a selector to narrow it down. Separate filters with commas, no spaces.

@e[type=cow]Only cows.
@e[type=cow,distance=..10]Cows within 10 blocks. ..10 means “up to 10”.
@e[type=cow,limit=1,sort=nearest]Just the single closest cow.
@a[tag=hero]Players with the tag “hero” (see /tag).
@a[name=Steve]The player named Steve.
@e[type=!player]Everything that is NOT a player. ! means “not”.
@e[type=cow]Only cows.
@e[type=cow,r=10]Cows within 10 blocks. r means radius.
@e[type=cow,c=1]Just the single closest cow. c means count.
@a[tag=hero]Players with the tag “hero” (see /tag).
@a[name=Steve]The player named Steve.
@e[type=!player]Everything that is NOT a player. ! means “not”.
Java and Bedrock spell two filters differently. Java: distance=..10 and limit=1,sort=nearest. Bedrock: r=10 and c=1. Use the switch at the top to see each one.
6

Where? Coordinates and the ~ squiggle

Every block has an address of three numbers: x (east/west), y (up/down), z (south/north).

To see your coordinates, press F3 and look for XYZ on the left. (On some laptops it's Fn + F3.)
To see your coordinates, turn on Show Coordinates in the world settings, or type /gamerule showcoordinates true.
100 64 -20Exact spot: always the same place in the world.
~ ~ ~Right here: where the command is running from (you, or the command block).
~ ~5 ~5 blocks above here. The number after ~ means “this many more”.
~3 ~ ~-23 blocks east and 2 blocks north. A minus sign goes the other way.
^ ^ ^5Caret ^: 5 blocks in front of where you're looking. The three ^ spots are left, up, forward.
/tp @s ^ ^ ^10

Zap 10 blocks forward, whichever way you're facing.

7

When it doesn't work

Red text means the game didn't understand. Check these:

  • Did you spell everything right? Item names use underscores: iron_sword.
  • Is there exactly one space between each part?
  • Are cheats on? (Lesson 1)
  • Are you using the Java way in Bedrock, or the other way around? Some commands are typed differently. Check the switch at the top.
  • Is there an extra or missing ], } or "?
⚠️ There is no undo button for commands. A big /fill or /kill can't be taken back. Try new ideas in a test world first!

Command blocks

A command block is a block that runs a command for you, whenever it gets a redstone signal or all the time. With them you can build traps, shops, teleporters, mini-games, and more.

1

Get a command block

  1. Switch to Creative: /gamemode creative
  2. Give yourself one:
    /give @s command_block
  3. Place it like any block.
On a server, the server owner must set enable-command-block=true. In your own world with cheats on, they just work.
Command blocks need Command Blocks Enabled turned on in the world's Cheats settings. It's usually on already.
2

Open it and type inside

  1. Look at the block and right-click it.
  2. Type your command in the Console Command box. The slash is optional here.
  3. Set the three buttons (next lessons explain them).
  4. Click Done. If you press Esc instead, your command is not saved!
  1. Look at the block and press LT (left trigger, the same button you use to place blocks).
  2. Type your command in the Command Input box. The slash is optional here.
  3. Pick the Block Type, Condition and Redstone settings on the left (next lessons explain them).
  4. Press B to close. It saves automatically.
You can only open command blocks in Creative mode.
3

Turning it on: Needs Redstone or Always Active

Needs RedstoneWaits for a signal. Put a button, lever, or pressure plate right on it or next to it.
Always ActiveTurned on by itself. No redstone needed.

Try it: set a command block to /time set night, Needs Redstone. Put a button on it and press it. Spooky!

4

The three colors

Impulse (orange)Runs once each time it gets turned on. Best for buttons.
Chain (green)Runs right after the block pointing into it runs. Used to do several things in a row.
Repeat (purple)Runs 20 times every second while it's on. Best for things that always check, like a speed pad.

To change the type, click the button that says Impulse until it says the one you want.

To change the type, use the Block Type dropdown.

Bedrock bonus: Delay in Ticks waits before running. 20 ticks = 1 second.
⚠️ A Repeat block that gives items or summons mobs will do it 20 times a second. That's 1,200 creepers a minute! Use Repeat for checking, and Impulse for giving.
5

Chains: doing several things in a row

Look closely at the sides of a command block: there's an arrow pattern. It shows which way the block “points”.

  1. Place an Impulse block with a button on it.
  2. Place a Chain block right where the first block's arrow points.
  3. Set the chain block to Always Active. (Chain blocks almost always should be.)
  4. Keep adding chain blocks in a line, each one where the last one points.

Now one button press runs the whole line, in order, super fast.

If a chain doesn't run, the arrow is probably pointing the wrong way. Break the block and place it again while facing a different direction.
6

Conditional: only if the last one worked

A Conditional block only runs if the block pointing into it succeeded. Unconditional (the normal setting) always runs.

Example: a shop. Pay 1 gold, get a sword.

Block 1: Impulse, Needs Redstone, with a button. It takes 1 gold ingot, but fails if you don't have any:

clear @p gold_ingot 1
clear @p gold_ingot 0 1

Block 2: Chain, Conditional, Always Active. Only runs if block 1 took the gold:

give @p iron_sword

No gold? No sword!

7

Who is “me” when a block runs it?

  • @p means the player closest to the block. That's usually the person who pressed the button.
  • ~ ~ ~ means the block's spot, not yours. ~ ~1 ~ is the space right on top of the block.
  • @s doesn't work by itself in a command block, because a block isn't a player. Use @p, or use /execute as (next lesson).
8

Commands inside commands: /execute

/execute wraps around another command, like a sentence with extra parts. Let's build one, piece by piece.

Step 1. A plain command. The block says hi:

say hi

Step 2. Add as = who does it. Now every player says hi. run always comes right before the inside command:

execute as @a run say hi

Step 3. Add at = where. at @s means “at that player's spot”. Inside execute, @s means the player we're doing it for right now. Now a chicken appears above every player:

execute as @a at @s run summon chicken ~ ~3 ~

Step 4. Add if = only when. Now it only happens to players standing on a gold block:

execute as @a at @s if block ~ ~-1 ~ gold_block run summon chicken ~ ~3 ~
as …Who runs it (changes what @s means).
at …Where it happens (changes what ~ ~ ~ means).
if … / unless …Only when something is true / not true.
run …Do this. Always last.
Read it out loud: “Execute as all players, at themselves, if the block below is gold, run summon chicken.”
9

Stop the chat spam

Command blocks post a message in chat every time they run. A Repeat block fills chat super fast. Turn it off:

/gamerule command_block_output false
/gamerule commandblockoutput false
